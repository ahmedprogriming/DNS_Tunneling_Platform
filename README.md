# DNS Tunneling Detection Platform
منصة ذكية لاكتشاف DNS Tunneling باستخدام التعلم الآلي وتحديد أولويات المخاطر.

## وصف المشروع (Project Description)
مشروع تخرج يهدف إلى بناء منصة قادرة على تحليل حركة مرور DNS لاكتشاف القنوات الخفية (Tunneling) التي يستخدمها المهاجمون لتهريب البيانات. يعتمد النظام على استخراج الخصائص السلوكية والإحصائية، ثم تصنيفها باستخدام نماذج التعلم الآلي (Machine Learning)، مع توفير محرك لتحديد أولويات المخاطر (Risk Prioritization Engine) لتقليل الإنذارات الكاذبة.

## التقنيات المستخدمة (Technologies)
* **اللغة:** Python 3.12
* **تحليل البيانات:** Pandas, NumPy
* **تحليل الشبكات:** Wireshark, Zeek
* **التعلم الآلي:** Scikit-learn
* **واجهة المستخدم:** Streamlit
